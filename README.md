# Aswini Developer Portfolio

Personal portfolio built with React, TypeScript, Vite and Tailwind CSS.

The original portfolio page layout, color palette, typography and project-card styling are retained. The application entry point is standard React + Vite; no hosted site-builder runtime is required.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Resume
